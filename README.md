# Сайт «Прикормка от суши»

**Прикормка от суши** — это сайт для моего сообщества ВКонтакте, где я помогаю предпринимателям, блогерам и творческим людям создавать контент с помощью нейросетей.

## 🎯 Цель проекта

Создать удобный онлайн-ресурс, где клиенты могут:
- Узнать обо всех услугах: тексты, изображения, видео, 3D-модели, сайты, боты, настройка AI-агентов.
- Оставить заявку или заказать консультацию.
- Связаться со мной через сообщество ВКонтакте или сайт.

## 🛠️ Что я предлагаю

- ✅ Генерация текстов, изображений, видео и аудио с помощью нейросетей.
- ✅ 3D-моделирование по фото (для печати, игр, визуализации).
- ✅ Настройка AI-агентов для автоматизации общения с клиентами.
- ✅ Промпт-инжиниринг — обучение и готовые подборки промптов.
- ✅ Создание сайтов и ботов для бизнеса.
